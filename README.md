# Rose Blossom Silkies

Website for Rose Blossom Silkies, Aura's silkie chicken farm: available birds, waffle orders, a fundraiser, and (later) auctions.

Built with Next.js (App Router), TypeScript, and Tailwind CSS. Supabase and PayPal are added in later phases.

## Status

| Phase | What | Status |
| --- | --- | --- |
| 1 | Static site with placeholder content | Done |
| 2 | Supabase: database, admin area, photo uploads | Not started |
| 3 | PayPal checkout, donations, waffle orders | Not started |
| 4 | Auctions with live bidding | Not started |

## Run it locally

Needs Node 20 or newer (built on Node 24).

```bash
npm install
npm run dev
```

Open http://localhost:3000. To test on your phone over wifi, run `npm run dev -- -H 0.0.0.0` and open `http://<your-computer's-LAN-IP>:3000` on the phone.

Other commands:

- `npm run build`: production build. Run this before pushing, because it catches type errors that `dev` lets slide.
- `npm run start`: serve the production build.
- `npm run lint`: ESLint.

## Editing content

All text, prices, and contact details live in `src/content/`:

| File | What's in it |
| --- | --- |
| `site.ts` | Farm name, tagline, about Aura, contact info, pickup and shipping notes, menu links |
| `birds.ts` | The bird list (moves to the database in Phase 2) |
| `waffles.ts` | Waffle menu and ordering note |
| `fundraiser.ts` | Fundraiser story, goal, and amount raised |

Search the project for `PLACEHOLDER` to find everything that still needs real info.

Prices are in **cents**: `6500` is $65.00. That avoids floating point rounding errors with money.

### Swapping in real photos

Drop the photo into `public/images/...` and update the `photo` path in the matching content file. Square photos work best for birds. JPG or WebP is fine. Next.js resizes them for each screen automatically.

The Facebook share preview is generated by `src/app/opengraph-image.tsx`. To use a real photo instead, delete that file and add `src/app/opengraph-image.jpg` at 1200x630.

## Project layout

```
src/app/         Pages. Each folder is a URL: app/birds/page.tsx is /birds
src/components/  Reusable pieces: header, bird card, progress bar, buttons
src/content/     All editable site content
src/types/       TypeScript shapes for the content
src/lib/         Small helpers (price formatting). Supabase and PayPal code goes here later
public/images/   Images served as-is
```

## Environment variables

Copy `.env.example` to `.env.local` and fill it in. `.env*` files are git-ignored (except the example). Phase 1 needs none.

Rules:

- Anything starting with `NEXT_PUBLIC_` is bundled into the browser JavaScript and is public. Only the Supabase URL and anon key go there.
- Everything else (PayPal secret, Supabase service role key) is only read in server code.
- On Vercel, set the same variables under Project Settings, Environment Variables.
